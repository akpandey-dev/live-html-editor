# Live HTML Editor

A lightweight, browser-based, interactive HTML editor built using pure HTML, CSS, and JavaScript, that lets you write, edit, and instantly preview HTML content.

This project is a experimental editor for quickly testing HTML directly inside the browser without needing any external setup or installation. The editor focuses on simplicity, fast execution, and a clean workflow.

## Features

- HTML editing
- CSS editing
- JavaScript editing
- Separate editors for JS, CSS and HTML
- Live preview
- Preview box hide and show toggle
- Simple and lightweight interface
- Built using pure HTML, CSS, and JavaScript
- No frameworks or external libraries
- Beginner-friendly structure

---

## What this project is

This is a simple live coding environment where you can:

- Write HTML, CSS, and JavaScript in separate editors
- Run code instantly in a live preview frame
- Toggle visibility of editors when needed
- Switch between minimal and structured UI modes (depending on version)

It’s not trying to be a full IDE. The goal is speed and clarity.

---

## Project Goal

The goal of this project is to create a minimal yet useful live code editor that can run entirely in the browser while remaining lightweight and easy to modify.
